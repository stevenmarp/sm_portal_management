Step 1: Create Directories
~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Navigate to **Portal Documents → Directories → New**.
2. Enter a name and optionally set a parent directory.
3. Toggle **Allow Portal Upload** if portal users should be able to add content.

Step 2: Add Followers
~~~~~~~~~~~~~~~~~~~~~~

1. Open a directory in form view.
2. In the chatter, click **Add Followers**.
3. Select the portal users (partners) who should have access.

Step 3: Upload Documents (Backend)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Go to **Portal Documents → Documents → New**.
2. Select the directory, upload a file, and save.
