Portal User
~~~~~~~~~~~

1. Log in to the customer portal.
2. Click the **Documents** card on the portal home page.
3. Browse directories — click a folder to see its contents.
4. If uploads are allowed, use the **New Sub-Directory** or **Upload Document** buttons.
5. Click the download icon next to any document to save it locally.

Backend User
~~~~~~~~~~~~

1. Go to **Portal Documents → Directories** to manage folders.
2. Go to **Portal Documents → Documents** to manage files.
3. Use the chatter to add/remove followers for access control.
